# Mini bilingual glossary: 10 core AI-agent terms (EN → ZH)

| # | English | Chinese (ZH) | Note |
|---|---|---|---|
| 1 | AI agent | 智能体 | autonomous program that perceives, decides, acts |
| 2 | LLM (Large Language Model) | 大语言模型 | foundation model behind most agents |
| 3 | Tool calling / function calling | 工具调用 | agent invokes external functions |
| 4 | MCP (Model Context Protocol) | 模型上下文协议 | open protocol connecting agents to tools/data |
| 5 | Prompt engineering | 提示词工程 | designing inputs that steer model behavior |
| 6 | Multi-agent system | 多智能体系统 | several agents cooperating on tasks |
| 7 | Task orchestration | 任务编排 | sequencing and routing work across agents/tools |
| 8 | Guardrail | 护栏 / 安全护栏 | constraints preventing harmful outputs |
| 9 | Hallucination | 幻觉 | confident but false model output |
| 10 | Human-in-the-loop (HITL) | 人在回路 | human approval inside an automated workflow |
