# 5 AI agent open-source projects worth onboarding

1. **LangGraph** (langchain-ai/langgraph) — graph-based orchestration for stateful agent workflows; the de-facto standard for controllable multi-step agents with checkpointing and human-in-the-loop.
2. **AutoGen** (microsoft/autogen) — framework for multi-agent conversations where role-playing agents cooperate to finish tasks; strong for research prototyping of agent teams.
3. **CrewAI** (crewAIInc/crewAI) — role-based agent crews with clear task delegation; the fastest path from idea to a working multi-agent pipeline in Python.
4. **OpenHands** (All-Hands-AI/OpenHands) — autonomous software-engineering agent that reads, edits, and runs code in a sandbox; the leading open Devin alternative.
5. **Browser Use** (browser-use/browser-use) — lets agents drive a real browser with vision + DOM access; the standard library for web-automation agents and the backbone of many task markets.

All five are MIT/Apache-licensed, actively maintained, and expose Python APIs an onboarding agent can call today.
